Automação visual profissional para sistemas legados.

O pyvizion entrega uma experiência de framework moderno, com API simples e documentação direta. Você automatiza telas sem API (ERP, Oracle Forms, Delphi, Citrix) detectando imagem e texto com segurança.

Começar agora Ver demonstração
pip install pyvizion 
from pyvizion import Vizion

vz = Vizion({"tesseract_lang": "por"})
vz.focus_window("Sistema Legado")
vz.click_image("menu_relatorios.png")
vz.click_text("Período", sendtext="01/01/2026{tab}31/01/2026")
vz.click_text("Executar", wait_until_found=True)

Quickstart

Fluxo mínimo para colocar em produção.

1. Instalar

pip install pyvizion

2. Validar

python -m pyvizion doctor

Tesseract é obrigatório.

3. Executar

from pyvizion import Vizion
vz = Vizion()
vz.click_image("ok.png")

Arquitetura, tecnologias e requisitos

Fluxo interno

Script Python
  -> API Vizion
    -> Captura (mss)
    -> Imagem (OpenCV)
    -> Texto (Tesseract)
    -> Mouse / teclado
    -> True / False / None / box

Stack e requisitos

  • Python 3.9+
  • Windows (suporte principal)
  • Tesseract OCR instalado
  • OpenCV, mss, PyAutoGUI
  • Tela do app visível

Sobre macros (o ponto da nova versão)

As macros de sendtext são opcionais. Se você não gosta, pode usar apenas texto direto.

Sem macro

vz.click_text("Código", sendtext="12345")
vz.click_text("Código")
vz.type_text("12345")

Com macro (quando precisa)

vz.click_text("Usuário", sendtext="admin{tab}senha{enter}")
vz.click_text("Código", sendtext="{ctrl}a{del}12345")
